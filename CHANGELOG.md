# Changelog

All notable changes use this file. Folio follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.3.0] - 2026-08-18

### Added

- Offline, interactive Flint chart specs compiled through the Plotly backend in standalone reports.
- Safe `bun run release -- <version>` automation for verified tag-driven releases.

## [0.2.0] - 2026-08-18

### Added

- Repository filter panel with per-project report counts in the archive.

## [0.1.1] - 2026-08-17

### Added

- Source-based npm and `bunx` distribution, with a packed-package smoke test.
- Served-report archive navigation and safer server metadata.
- Contextual CLI help, shell completion, strict option parsing, and structured JSON errors.
- Cross-platform CI and npm trusted-publishing workflow.

## [0.1.0] - 2026-08-17

- Initial local-first report compiler, catalog, review UI, archive, source viewer, standalone binaries, and coding-agent skill.
